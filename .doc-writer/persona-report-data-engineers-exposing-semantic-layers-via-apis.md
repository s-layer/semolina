## Summary

The 0.9.1 changes reach this persona through codegen. A Databricks metric view written by
hand now gets `semantic_format=` from its native `format`, and the models guide says which
format types and options map, which don't, and what error an invalid one raises. The
changelog explains why `codegen --check` reports drift after the upgrade (HUGEINT sums,
derived metrics, native formats), and the DuckDB grain note now says the pinned extra runs
grains. The one friction: the Databricks section of the backends guide, where a
Databricks-only reader starts, described codegen without saying any metadata or format is
read.
